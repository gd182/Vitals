# Vitals

Vitals показывает загрузку процессора, видеочипа и оперативной памяти в строке
меню macOS. В панелях можно посмотреть историю нагрузки, доступные показания
температуры и процессы, которые используют больше всего ресурсов. Что показывать
и как часто обновлять данные, можно выбрать в настройках.

## Возможности

- Загрузка и температура процессора, список самых активных процессов.
- Нагрузка на GPU и использование памяти, а также дополнительные показатели, если их поддерживает драйвер.
- Занятая, свободная и общая оперативная память, список процессов, которые занимают больше всего памяти.
- Графики недавней нагрузки с отметками времени, настройкой порогов и цветов.
- Отдельные интервалы обновления для открытых панелей и фоновой работы, процессов и температуры.
- Выбор значков в строке меню, порядка и видимости секций, компактной или просторной компоновки.
- Светлая и тёмная темы или автоматический выбор по настройкам macOS.
- Автозапуск при входе в систему. Панели закрываются при переходе в другое приложение или на другой рабочий стол.

При первом запуске открывается небольшое окно начальной настройки.
Позже к нему можно вернуться из настроек приложения.

## Требования

Для работы нужна **macOS 14.6 или новее**. Поддерживаются Mac с процессорами
Intel и Apple Silicon.

Для сборки нужен **Xcode 26.2 или новее**, Swift 6.2+ и macOS SDK.
Устанавливать сторонние библиотеки не нужно. Проект использует режим языка Swift 5,
но зависит от новых возможностей компилятора, поэтому Xcode 15 не подойдёт.

## Доступность показателей

Набор показателей зависит от модели Mac и драйверов. На одних устройствах
доступно больше данных, чем на других:

- Если прочитать датчик температуры процессора не удаётся, отображается `N/A`.
- Показатели GPU различаются у драйверов Intel, AMD и Apple. Счётчики render,
  tiler и ANE доступны не на каждом Mac; неподдерживаемые счётчики могут показывать ноль.
- На Apple Silicon процессор и GPU используют общую память. Показания памяти GPU
  не стоит воспринимать как объём памяти отдельной видеокарты.
- macOS может ограничивать доступ к данным процессов. Процесс, который использует
  несколько ядер, может показывать загрузку выше 100%.
- Процент занятой RAM показывает использование памяти, а не давление на память
  (memory pressure) из «Мониторинга системы».

Приложение собирается для обеих архитектур, но не все модели Mac проверены на
реальном оборудовании. Если какого-то показателя не хватает, укажите в сообщении
об ошибке модель Mac, процессор, GPU и версию macOS.

## Сборка из исходников

```sh
git clone https://github.com/gd182/Vitals.git
cd Vitals
open Vitals.xcodeproj
```

В Xcode выберите схему `Vitals` и запустите приложение. Его значки появятся
в строке меню, а не в Dock.

Чтобы собрать приложение сразу для Intel и Apple Silicon из терминала:

```sh
xcodebuild -project Vitals.xcodeproj -scheme Vitals -configuration Release \
  -destination 'generic/platform=macOS' -derivedDataPath /tmp/VitalsBuild \
  ARCHS='arm64 x86_64' ONLY_ACTIVE_ARCH=NO CODE_SIGNING_ALLOWED=NO build
lipo -archs /tmp/VitalsBuild/Build/Products/Release/Vitals.app/Contents/MacOS/Vitals
```

Приложение появится в `/tmp/VitalsBuild/Build/Products/Release/Vitals.app`.
Это сборка без подписи, предназначенная для разработки. Для публичного релиза
также понадобятся подпись и нотарификация Apple.

## Проверки

```sh
bash Tests/run-checks.sh
```

Чтобы дополнительно проверить панели и окна настроек и получить скриншоты,
запустите эту команду в активном сеансе macOS:

```sh
bash Tests/run-checks.sh --ui
```

В [описании тестов](Tests/README.md) указано, что проверяется автоматически,
а что нужно проверить вручную. Локальные проверки пройдены на Xcode 27.
GitHub Actions настроен на Xcode 26.2, сборку для обеих архитектур и тесты без
графического интерфейса. Показания датчиков и поведение окон всё равно нужно
проверять на реальном Mac.

Для ручной проверки под нагрузкой есть `test/load.py`: он нагружает все ядра
процессора, пока его не остановить сочетанием Ctrl+C. Для него нужен Python 3.
Ни приложение, ни CI не запускают этот скрипт автоматически.

## Как это устроено

<p>
  <img src="https://skillicons.dev/icons?i=swift" width="40" height="40" alt="Swift" />
  <img src="https://skillicons.dev/icons?i=cpp" width="40" height="40" alt="C++" />
</p>

Интерфейс написан на SwiftUI, а системные показатели собирает код на C++20.
Они связаны через Objective-C++. За чтение температуры через SMC отвечает Swift-код.

- `Vitals/Core/`: сбор данных через Mach, sysctl, libproc и IOKit, а также работа с SMC.
- `Vitals/Bridge/`: связь между Swift и C++ через Objective-C++.
- `Vitals/ViewModels/`: фоновое обновление данных и история для графиков.
- `Vitals/Views/`: строка меню, панели, настройки и графики.

Vitals читает системные данные локально и не запускает `ps` для получения
списка процессов. Настройки сохраняются в UserDefaults. История графиков имеет
фиксированный размер и остаётся в памяти, а не записывается постоянно на диск.
